Pertanyaan Dosen: Konsep "Multi-Kernel" di Proxmox

Pertanyaan: "Apakah ketiga kontainer ini menggunakan kernel yang berbeda?"

Jawaban Teknis: Di tingkat OS virtualization LXC, ketiga kontainer berbagi (*shared*) satu Kernel Linux milik Host Proxmox (`pve-lab`). Namun, di level user-space runtime, sistem menerapkan Multi-Userland Execution: Alpine menggunakan musl libc yang ultra-ringan, sementara Ubuntu dan Debian menggunakan GNU glibc. Isolasi dilakukan via Linux Namespaces (PID, Mount, UTS, IPC, Net) dan cgroups v2.

Pertanyaan Dosen: Peran Tailscale dalam Sistem Terdistribusi

Pertanyaan: "Mengapa menggunakan Tailscale dan bukan IP lokal biasa?"

Jawaban Teknis: Tailscale membangun Zero-Trust WireGuard Overlay Mesh Network. Ini memungkinkan komunikasi antar-node terisolasi dari LAN luar, terenkripsi point-to-point tanpa perlu port forwarding publik, serta port Database 5432 di-bind khusus ke interface Tailscale sehingga aman dari serangan sniffing atau lateral movement.
